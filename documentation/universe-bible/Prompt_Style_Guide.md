# Prompt Style Guide

Every prompt MUST contain the following elements in the production notes, translated into the final AI string:

1. Asset Name
2. Category
3. Lore Summary
4. Physical Description
5. Materials
6. Shape Language
7. Color Palette
8. Energy Effects
9. Lighting
10. Camera
11. Rendering Style
12. Scale
13. Mood
14. Negative Prompt
